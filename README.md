# Codespace
Django web project for CODEHOOD100 program.
## Setup
- Clone branch:
  `git clone 'https://github.com/@Abduqod1rr/codespace'`
- Install requirements:
  `pip install requirements.txt`
- Docker:
  - `docker-compose up -d`
- Without Docker:
  - `python manage.py migrate`
Run at: http://127.0.0.1:8000/
## Deployment
- Set your SECRET_KEY in environment variable
- SECRET_KEY
Enable the arguments. Make migrations and run collectstatic.
